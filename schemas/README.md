# ProvenanceX Schemas

This directory contains formal JSON Schemas governing ProvenanceX evidence objects, manifests, and verification reports:

* `evidence-manifest.schema.json`: Portable evidence bundle manifest schema.
* `correlation-result.schema.json`: Cross-layer evidence correlation schema.
* `policy.schema.json`: YAML/JSON policy specification schema.
* `experiment-result.schema.json`: Supply-chain attack benchmark metrics schema.
